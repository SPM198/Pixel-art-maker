# Pixel Art Studio

¡Bienvenido a **Pixel Art Studio**, una aplicación web interactiva y moderna diseñada para crear, editar y exportar creaciones de arte en píxeles directamente desde el navegador!

Este proyecto fue desarrollado como una herramienta creativa minimalista y funcional, utilizando tecnologías web nativas.

---

## Características Principales

- **Sistema de Capas Avanzado:** Crea múltiples capas, reordenalas (subir/bajar), renuévalas con un clic, contróla su visibilidad, dúplicalas o elimínalas.
- **Temas Dinámicos (Dark / Light Mode):** Alterna fluidamente entre modo oscuro y modo claro con una interfaz totalmente adaptada mediante variables CSS.
- **Herramientas de Dibujo Esenciales:** Lápiz, borrador, paleta de colores personalizada y modo espejo integrado para diseños simétricos.
- **Personalización de Cuadrícula:** Ajusta el tamaño del lienzo según tus necesidades creativas.
- **Exportación Rápida:** Guarda tus obras maestras directamente en formato de imagen con un solo clic.

---

## Tecnologías Utilizadas

- **HTML5:** Estructura semántica de la aplicación.
- **CSS3 (Variables CSS):** Estilos modernos, diseño modular y soporte nativo para temas claros y oscuros.
- **JavaScript (ES6+):** Lógica del lienzo, manipulación del DOM, gestión de estados y control de capas.
